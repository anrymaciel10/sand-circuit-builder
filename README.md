# Arena Trainer AI

Crie um app onde eu consiga montar treinos funcionais para montar o circuito funcional do life training. Eu quero que seja tudo automatizado, que eu coloque apenas o material que será utilizado e que o sistema me dê ideias de exercícios funcionais na areia que eu possa utilizar, essas ideias pode ser com nome dos exercícios, com link direcionando para vídeos (YouTube, Instagram, sites de treinamento, etc), gifs e imagens dos exercícios.

This project was built with [Lovable](https://lovable.dev).
